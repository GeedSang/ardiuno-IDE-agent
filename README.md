# Arduino IDE Agent

一个面向 Arduino 初学者的 IDE 内置调试 Agent。它不只解释错误，还会读取当前工程、调用真实编译工具、定位错误行，并在用户确认后执行最小修复。

> GitHub 仓库沿用课程阶段命名 `ardiuno-IDE-agent`，插件内部使用正确拼写 Arduino。

## 当前功能

- 扫描 USB 串口并提示开发板选择
- 编译当前打开的 `.ino` 工程
- 识别缺少分号、缺少库、名称未定义、串口和板型问题
- 一键跳转到错误行
- 用户确认后自动补充分号
- 自动安装 Adafruit NeoPixel，并修正错误的头文件引用
- 修复完成后立即重新编译
- 在左侧保存修改时间、原因和修改前后内容
- 上传成功后提醒用户进行实物验证

## 人与 Agent 的分工

Agent 负责读取代码、编译日志、板型和串口信息，给出最小修改并保留记录。用户负责确认真实接线、供电、开发板型号和实物是否按预期运行。涉及硬件操作或证据不足时，Agent 会停下来等待用户确认。

## 开发过程

### 1. 从独立窗口改为 IDE 侧栏

早期版本使用单独面板，用户无法同时看代码和诊断结果。之后改为 Arduino IDE 左侧原生 TreeView，使代码区和 Agent 同时显示。

### 2. 从通用提示改为真实编译

早期“编译检查”错误地执行 `arduino-cli compile .`，检查的可能不是当前工程。现在插件读取当前活动的 `.ino` 文件，并以其文件夹作为编译目标。

### 3. 从错误分类改为具体建议

插件现在解析第一条编译错误，提取文件、行号和错误内容。例如：

- `expected ';' before 'strip'`：提示检查上一条语句并补分号
- `No such file or directory`：识别缺少的头文件和代码库
- `was not declared in this scope`：提示检查名称、声明和作用域

### 4. 从建议改为确认后执行

当修复足够明确时，Agent 会询问用户是否执行。补分号和安装 NeoPixel 库都需要用户点击确认。每次修改只处理当前问题，不重写整份代码。

### 5. 增加修改记录

所有自动修改都会记录时间、文件、原因、修改前和修改后内容。记录显示在左侧“修改记录”分组中，方便回看 Agent 做过什么。

## 实验案例

`examples/` 提供六个由同一声音传感器与 NeoPixel 项目派生的案例：正常基线、缺少分号、端口或板型错误、缺少库、传感器引脚错误、阈值不合理。

## 构建

```powershell
npm install
npm run build
npx vsce package
```

## 当前限制

- 默认按 Arduino Uno 和 AVR 工具链编译
- Agent 无法直接观察真实接线、供电和灯光效果
- 自动修复目前只覆盖证据明确且风险较低的问题
- 其他代码库仍需要补充“头文件到库名称”的映射
