# Hardware reference images

This directory contains a deliberately small offline subset of breadboard-view
graphics from `fritzing/fritzing-parts`. They are used only when the requested
model can be matched reliably. Unknown or ambiguous modules use the Agent's
generic illustration instead of pretending that a different product is exact.
